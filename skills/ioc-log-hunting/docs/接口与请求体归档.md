# API / 样例 / tableId 归档

所有接口均为用户提供，base 同域 `soar.sangfor.com.cn`（内网直连用 `soar-inner.sangfor.com.cn:30001`）。

## 4 个核心接口

### ① /gateway/log-search-center-service/datalake/v1/ckQueryList
日志列表/分页查询。样例（NGES 病毒日志 26）：
```json
{
  "fromDate": "2026-09-02 16:06:25", "toDate": "2026-09-03 16:06:25",
  "tableId": [26], "searchString": "",
  "fieldList": ["recordTime","threatClass","threatType","threatSubType","hostIp","severity","processHandleState"],
  "pageNo": 0, "pageSize": 60,
  "constrains": [
    {"fieldAlias":"客户","fieldName":"customer","fieldOperater":"=","fieldValue":"97988530"},
    {"fieldName":"productType","fieldAlias":"上报设备","fieldOperater":"=","fieldValue":"NGES"},
    {"fieldName":"hostIp","fieldAlias":"主机IP","fieldOperater":"=","fieldValue":"192.168.1.108"}
  ],
  "quickSearch": {}, "datalakeClusterName": "", "order": {}
}
```

DNS 过滤检索样例（filter 语法放 searchString，constrains 只放客户）：
```json
{
  "fromDate": "2026-09-02 16:06:25", "toDate": "2026-09-03 16:06:25",
  "tableId": [20], "searchString": "filter srcIp=\"10.88.48.47\"",
  "fieldList": ["tenant","recordTimestamp","srcIp","srcPort","dstIp","dstPort","queries"],
  "pageNo": 0, "pageSize": 60,
  "constrains": [{"fieldAlias":"客户","fieldName":"customer","fieldOperater":"=","fieldValue":"97988530"}],
  "quickSearch": {}, "datalakeClusterName": "", "order": {}
}
```

### ② /gateway/log-search-center-service/datalake/v1/ckQueryDetail
单条明细，按 uuId。样例（DNS 表内）：
```json
{
  "fromDate": "2026-09-02 16:06:25", "toDate": "2026-09-03 16:06:25",
  "tableId": [20], "searchString": "filter srcIp=\"10.88.48.47\"",
  "constrains": [
    {"fieldName":"uuId","fieldAlias":"","fieldOperater":"=","fieldValue":"dns_log-1788413909-tBSCM"},
    {"fieldAlias":"客户","fieldName":"customer","fieldOperater":"=","fieldValue":"97988530"}
  ],
  "datalakeClusterName": ""
}
```

### ③ /gateway/log-search-center-service/datalake/v1/ckCount
统计当前过滤条件下命中总条数。样例：
```json
{
  "fromDate": "2026-09-02 16:06:25", "toDate": "2026-09-03 16:06:25",
  "tableId": [20], "searchString": "filter srcIp=\"10.88.48.47\"",
  "constrains": [{"fieldAlias":"客户","fieldName":"customer","fieldOperater":"=","fieldValue":"97988530"}],
  "quickSearch": {}, "datalakeClusterName": ""
}
```
> 返回 `data.total` = 精确匹配总数（已吃透 filter：必空条件返回 0，可信；空 filter 返回全表量）。

## 表格 tableId
- `[26]` 终端安全日志（NGES 病毒/进程告警；无外联IP/域名，含文件哈希类证据）— 用户首样例行
- `[20]` DNS 日志
- `[100]` TCP 日志
- `[28]` 终端遥测安全日志

## 检索语法要点（已验证）
- 内容过滤放 `searchString`：`filter <字段>="精确值"`；`filter <字段> LIKE "%含%"`；`AND` 组合
- **不可用**：`=` 带 `*` 通配（返回空）、`CONTAINS`（code 9603 只允许一个全文检索条件）、`EXIST`（语法错）、无空格粘连
- `constrains` 只放 `customer`（客户作用域）；乱塞内容字段会 code 9001 / 9001
- `order":{"recordTime":"desc"}` 时间降序有效；`pageSize` 可到 300+；翻页到顶依据 **ckCount.total** 判断（`isLimit` 字段不可信，一直 False 不代表到底）

## 验证网络关键结论
- constrains 能跑的合法组合：①空 ②customer(+productType 可再 +hostIp)。**不能**放内容字段过滤。
- 业务检索真正入口是 **searchString 的 `filter`**。
- 各表 device(productType) 由客户真实上报决定：绝味 DNS 由 **SIP**(产品 SIP / 采集 STA) 上报，NGES 不产 DNS。
