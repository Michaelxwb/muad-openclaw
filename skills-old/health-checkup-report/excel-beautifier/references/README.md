# excel-beautifier

为 Excel (.xlsx) / CSV (.csv) 表格统一套用视觉规范的轻量工具。内置两套主题（classic / modern），自动识别表头、数据区与列类型，一键完成字体、颜色、边框、数字格式、语义色、行高、页面设置。CSV 输入时自动将纯数据直出为规范 .xlsx（适合 AI 工具生成报告的规范输出）。

适用于：安全/合规检查清单美化、汇报材料标准化、AI 工具（openclaw 等）生成报告的规范输出。

## 快速开始

```bash
pip install -r requirements.txt        # 仅安装核心依赖 openpyxl
pip install Pillow                      # 仅当需要水印功能时

python3 scripts/cli.py style 输入.xlsx -t classic -o 输出.xlsx
```

## 两种主题怎么选

| 主题 | 视觉特征 | 适用场景 |
|------|----------|----------|
| **classic 经典清单** | 宋体、深蓝表头 `#1F497D`、统一浅蓝底 `#DCE6F2`、左对齐、无斑马纹 | 安全/合规检查清单、台账、加固手册、验收单等**清单类**文档 |
| **modern 现代汇报** | 微软雅黑、主蓝 `#1F4E79` + 辅蓝 `#0D51D9`、隔行斑马纹 `#F2F6FC`、居中表头 | 汇报材料、对外交付、经营分析、月报周报等**汇报类**文档 |

两套主题均基于 SeerDesign 设计规范，语义色、行高、页边距等规则完全一致，仅整体气质不同。

## 三种调用方式

### 1. 命令行（CLI）

```bash
# 经典清单风格，输出新文件
python3 scripts/cli.py style in.xlsx -t classic -o out.xlsx

# 现代汇报风格，覆盖原文件
python3 scripts/cli.py style in.xlsx -t modern

# 附加水印（自动启用，文字自定）
python3 scripts/cli.py style in.xlsx -t modern -o out.xlsx --watermark 内部资料

# CSV 直出规范表格（编码自动识别 utf-8/gbk，默认生成同名 .xlsx）
python3 scripts/cli.py style report.csv -t classic -o report.xlsx
```

### 2. MCP（供 AI 工具调用）

在 MCP 客户端配置中注册：

```json
{
  "mcpServers": {
    "excel-beautifier": {
      "command": "/绝对路径/python3",
      "args": ["/绝对路径/excel-beautifier/mcp_server.py"]
    }
  }
}
```

暴露 3 个工具：
- `beautify_excel`：美化表格（file_path / theme / output_path / watermark）
- `list_templates`：列出主题
- `show_template`：查看主题配置

### 3. Python 库调用

```python
from excel_beautifier import process

process(
    input_path="in.xlsx",
    output_path="out.xlsx",
    theme="classic",          # 或 "modern"
    watermark_text=None,      # 传文字即启用水印
)
```

## 语义色规范（重要，研发必读）

表格中存在**等级/风险**、**状态**、**结果**、**优先级**或**攻击**列时，工具会按以下枚举值对**文字**着色（背景保持不变）。列名的识别规则：表头含「等级/级别/风险」→ 等级列；含「状态」→ 状态列（覆盖处置状态、推送状态等）；含「结果」→ 结果列（覆盖处置结果等）；含「优先级」→ 优先级列（覆盖修复优先级等）；含「攻击」→ 攻击列（覆盖攻击结果、攻击状态，该列的「成功/失陷」按**负面红色**处理，与处置/推送成功的绿色区分）。含「描述/说明/详情/备注/内容/举证/建议/措施」的表头列不参与识别。

> **处理前自动清除原样式**：工具会先清除表格原有的单元格样式（字体/填充/边框/数字格式/条件格式），再统一按主题规则渲染，保证输出完全一致；原值、公式、合并单元格不受影响。

**请按规范命名枚举值，否则无法命中着色。**

### 等级列（level_map）

| 枚举值 | 颜色 | 色值 |
|--------|------|------|
| 失陷、严重 | 深红 | `#82010E` |
| 高危、高 | 红 | `#CF171D` |
| 中危、中 | 橙 | `#FA721B` |
| 中低危 | 琥珀 | `#FDAA1D` |
| 低危、低 | 灰 | `#6F7785` |
| 信息 | 青 | `#0BA7B5` |
| 安全、无风险 | 绿 | `#12A679` |
| 存在风险 | 琥珀 | `#FDAA1D` |

### 状态列（status_map）

| 枚举值 | 颜色 | 色值 |
|--------|------|------|
| 故障、异常、失败、推送失败 | 红 | `#CF171D` |
| 正常 | 蓝 | `#1C6EFF` |
| 在线、健康、已修复、已完成、已开启、处置完成、已处置、处置成功、推送成功、已推送、成功 | 绿 | `#12A679` |
| 离线、已遏制、该配置不支持此版本 | 灰 | `#6F7785` |
| 未接入、待接入、未处理、待处理、未修复、待处置、处置中、未加白、待推送、推送中、未推送 | 琥珀 | `#FDAA1D` |

### 结果列（result_map）

表头含「结果」的列（如处置结果、检查结果）按以下枚举着色：

| 枚举值 | 颜色 | 色值 |
|--------|------|------|
| 成功、拦截、命中 | 绿 | `#12A679` |
| 失败、绕过、失陷 | 红 | `#CF171D` |
| 未知 | 灰 | `#6F7785` |

### 攻击列（attack_map）

表头含「攻击」的列（如攻击结果、攻击状态）按以下枚举着色。**注意：攻击场景的成功/失陷是攻击方得手，对防守方是负面，故按红色处理**（与处置结果/推送状态的「成功」绿色语义相反）：

| 枚举值 | 颜色 | 色值 |
|--------|------|------|
| 成功、失陷、失败、绕过 | 红 | `#CF171D` |
| 拦截、命中 | 绿 | `#12A679` |
| 未知 | 灰 | `#6F7785` |

> 攻击列规则**最后应用**，会覆盖「结果/状态」列组对「攻击结果/攻击状态」列的命中，保证「成功」在攻击列恒为红色。

### 优先级列（priority_map）

表头含「优先级」的列（如修复优先级）按以下枚举着色，色值与等级列保持同语义：

| 枚举值 | 颜色 | 色值 |
|--------|------|------|
| 急需修复、立即修复、紧急、高危、高 | 红 | `#CF171D` |
| 尽快修复、中危、中 | 橙 | `#FA721B` |
| 建议修复 | 琥珀 | `#FDAA1D` |
| 低危、低、择期修复、暂缓 | 灰 | `#6F7785` |

> 语义色定义集中在 `scripts/excel_beautifier/themes/shared_semantic.json`，修改一处对所有主题生效。匹配规则：精确匹配优先，其次按最长关键词包含匹配（如「中低危」优先于「中」）。
>
> **自定义补充**：若你的取值不在枚举内（如「攻击成功」「已闭环」），直接在该文件的 `status_map` / `result_map` / `priority_map` / `attack_map` 里新增一行 `"取值": "色值"` 即可，无需改代码。若新取值与现有键存在包含关系，加更长键会优先命中（如「攻击成功」优先于「成功」）。

### 其他自动能力

- **涨跌条件格式**：classic 只作用于表头含「增长」的百分比列（正红 `#E65050` / 负绿 `#59B22D`）；modern 作用于表头含「增长/涨幅/跌幅/涨跌/同比/环比」的数值列（正红 `#C00000` / 负绿 `#00B050`），不会误染普通数字列（如端口号）
- **数字格式**：数值列自动加千分位、百分比列自动转 `0.0%`、日期列自动 `yyyy-mm-dd`
- **行高自适应**：最短 24 点，长文本自动撑高，上限 62 点（超长字段不会撑爆行高）
- **页面设置**：classic 纵向 A4 适应宽度；modern 横向 A4 适应宽度

## 水印说明

水印**默认关闭**（无需安装 Pillow）。需要时：
- CLI：`--watermark 文字`（自动启用）
- MCP：`watermark` 参数
- 主题配置：`watermark.enabled` 改为 `true`

水印为半透明斜置文字图片，覆盖数据区顶部约 60 行可视区域，跨 macOS/Windows/Linux 自动匹配中文字体。

## 常见问题

- **支持 .xls / .csv 吗？** 支持 `.csv`（编码自动识别 utf-8/gbk，逗号/Tab 分隔，首行即表头，输出 .xlsx）。不支持旧版 `.xls`，请先另存为 .xlsx 再处理。
- **多 Sheet 会全部处理吗？** 所有含可靠表头的 Sheet 都会处理；封面/目录等无表头页自动跳过。
- **标题行会被强制合并吗？** 只有检测到标题行且该行原本无合并单元格时才会合并，不会破坏已有结构。
- **处理后行高固定，内容被截断？** 行高上限 62 点（约 4 行）。如需显示更多内容，将主题 JSON 中 `body.max_height` 调大（如 92）。
